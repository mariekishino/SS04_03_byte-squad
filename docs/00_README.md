# 宇宙通信士の圧縮ラボ：エージェント向け実装依頼

## この資料の目的

圧縮と復元の仕組みを、各過程を確認しながら学ぶブラウザゲームを実装するための仕様書です。会話で提案した宇宙通信パズルを、初回実装できる範囲に具体化しています。仮称は「宇宙通信士の圧縮ラボ」です。

見た目と操作体験は、ユーザー指定の「1980〜90年代の2Dアーケード＋ASCII端末風」を採用します。インベーダー風の整列した編隊、自機、ドット表現、等幅文字でゲーム画面を構成してください。デザインの詳細は06にあります。

ユーザーの目的は、圧縮・展開の概念と操作を理解することです。最初の版ではRLEによる圧縮・復元を学び、実際のファイル保存やZIPの展開は次の段階で扱います。MVPをZIPツールと説明しないでください。

学習の道筋は「バイト列の圧縮・復元（MVP）→ 実ファイルの保存・読み込みと復元（Phase 2）→ 別の方式の比較（Phase 3）→ アーカイブとZIPの展開（Phase 4）」です。MVPはファイルの圧縮・展開を学ぶ入口と位置付けます。

## 実装エージェントへの依頼

1. 全資料と、実装先リポジトリに適用される指示を読む。
2. 既存プロジェクトがある場合はその構成を確認し、既存の設計・依存関係を尊重する。新規なら04の推奨構成を使う。
3. まずMVPを最後まで実装する。計画や静的モックだけで完了にしない。
4. 実際の圧縮結果に基づいて、容量・途中経過・復元結果を表示する。画面用の固定値で処理を偽装しない。
5. 05の受け入れ条件を検証し、起動方法・変更点・検証結果・未実装事項を報告する。

通常のUI細部や命名はエージェントの判断で決めてよい。ここに記載した数値、圧縮規則、学習目的を変える場合は、理由を明示する。

## MVPの範囲

- 日本語UI、宇宙通信の世界観、5問のミッション。
- 2Dアーケードのプレイフィールド、ASCII調の編隊・自機・HUD。詳細は06に従う。
- RLEと無圧縮の選択、手動の組作成、圧縮・復元のステップ再生。
- 前へ／次へ／自動再生／一時停止／リセット。
- バイト数の比較、完全一致判定、失敗からの修正。
- 1～64文字の半角英大文字を扱う自由実験モード。
- PCを中心に、狭い画面でも操作できるレスポンシブ画面。

## 初回実装に含めないもの

本物のZIP、任意ファイルの取り込み・ダウンロード、LZ77・ハフマン符号化、ログイン、バックエンド、オンラインランキング、生成AI呼び出し、3D空間、課金、タイムアタック。

これらは拡張候補です。初回の完成を遅らせる追加実装はしないでください。

## 成功の基準

プレイヤーが「規則を使って表現を変え、同じ規則で元のバイト列を復元する」「圧縮が逆効果になる場合もある」と、自分の操作と結果から説明できること。
